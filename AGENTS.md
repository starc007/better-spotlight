# better-spotlight

## Commit convention

Use Conventional Commits:

- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation only
- `refactor:` code change that neither fixes nor adds
- `perf:` performance improvement
- `test:` adding/correcting tests
- `chore:` tooling, deps, config

Examples: `feat: add global hotkey toggle`, `fix: caret spacing in input field`

## Stack

- GPUI 0.2 (crates.io) — GPU-rendered UI, macOS PopUp window kind for the overlay panel
- `icns` + `image` crates decode app icons
- Run tests with `cargo test`
